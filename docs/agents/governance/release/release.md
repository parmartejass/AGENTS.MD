# Release

Jurisdiction: release evidence, rollback readiness, and the closure record.

- Release evidence MUST identify each applicable owning jurisdiction and its witness.
- Rollback readiness MUST be verified against the release artifact, not asserted.
- Behavior changes MUST verify rollback leaves no inconsistent data state.
- Each closure record MUST carry a stable identifier and show what closed, where its durable facts live, how it was verified, and residual risk.
