# Evidence

Jurisdiction: invariant witnesses, the authority-application witness, and the verification-command location.

## Invariants

- MUST prove each affected invariant with a deterministically reproducible witness.

## Authority application

- MUST tie each decision-critical decision to the owner obligations applied and the evidence of their application (the authority-application witness).

## Verification commands

- Repeatable verification commands MUST live only in root README Checks.
